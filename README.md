# 🚀 ABTalks – 60-Day Coding Challenge Redesign

A modern, mobile-first redesign of the ABTalks platform focused on making the 60-day coding journey more engaging, motivating, and portfolio-driven.

The redesign keeps students focused on consistency while encouraging them to build projects, maintain GitHub activity, and showcase their work on LinkedIn.

# 💡 Thoughtful Product Features

Instead of only redesigning the interface, I introduced features that improve the overall student experience.

### 🔥 Daily Momentum

Shows yesterday's progress, today's focus, and tomorrow's goal in one place to encourage consistency.

---

### 📂 Portfolio Health

Connects daily challenge completion with long-term portfolio growth using GitHub activity, projects, LinkedIn visibility, and learned skills.

---

### 🏅 Achievement Timeline

Displays both unlocked and upcoming milestones, motivating students to continue the challenge.

---

### 📅 Weekly Milestones

Breaks the 60-day challenge into smaller goals, making long-term progress feel achievable.

---

### 🌍 Community Section

Creates a sense of belonging through leaderboard previews and active learner statistics.

---

### 🎉 Celebration Feedback

Confetti, XP rewards, and success feedback make challenge completion more rewarding.

---

# ⚠️ Edge Cases Handled
